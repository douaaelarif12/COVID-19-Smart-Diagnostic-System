# Modèle entraîné

Le modèle n'est pas inclus dans ce dépôt. Placez le fichier entraîné à cet emplacement :

```text
model/covid_detector.h5
```

Copiez ensuite `class_names.example.txt` vers `class_names.txt` et adaptez l'ordre des classes à celui utilisé pendant l'entraînement. L'ordre ne doit jamais être déduit uniquement à partir du nombre de sorties du réseau.
